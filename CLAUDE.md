# Split the Bill

A client-side web app to split a restaurant bill among friends.

## Context Loading

Do NOT read all files upfront. Load context based on the task:

- **Building features or fixing bugs?** → Read `specs/requirements.md`
- **UI/UX work?** → Read `specs/ux-design.md`
- **Architecture or refactoring?** → Read `specs/architecture.md`


## Tech Stack

React + TypeScript + Vite + Tailwind CSS. Client-side only — no backend.

## Commands

- `npm install` — install dependencies
- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run lint` — run linter
